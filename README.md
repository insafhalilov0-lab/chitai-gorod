# chitai-gorod

Сайт книжного магазина «Читай-город».

## Что использовал
- HTML: структура, `<head>`, `<body>`
- Мета-теги: `charset`, `author`, `description`, `keywords`, `viewport`
- Семантика: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`
- Текст: `<h1>`-`<h2>`, `<p>`, `<strong>`, `<em>`, `<br>`, `<hr>`
- Списки: `<ul>`, `<ol>`, `<li>`
- Ссылки: обычные, якоря, `mailto:`, `target="_blank"`, `rel="noopener"`
- Таблицы: `<table>`, `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`, `colspan`
- Формы: `<form>`, `<label>`, `<input>` (text, email, checkbox), `<select>`, `<option>`, `<textarea>`, `<button>`
- Дополнительно: `<details>`, `<summary>`, `<progress>`, `<blockquote>`, `<cite>`, `<code>`, `<address>`, `<time>`, `<div>`, `<span>`
- Язык разметки: Markdown (README)

## О чём сайт
Книжный магазин: каталог, мероприятия, клуб читателей, контакты.
